# Artículos

**Módulos:** articulos.

Código único, nombre, descripción y Activo/Inactivo. Las compras nuevas necesitan artículo activo y las referencias existentes se preservan.

## Operar

1. Elegir el módulo permitido.
2. Consultar/filtrar y abrir Nuevo o Editar.
3. Completar campos/referencias y guardar.
4. Revisar mensaje y resultado; no forzar borrado por fuera del sistema.

Claves inmutables al editar; DELETE cuando lo permite la integridad. Activo/Inactivo conserva historial.
